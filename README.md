# Async Task Manager

Асинхронный инструмент на Python для проверки доступности веб-ресурсов (HTTP/HTTPS) и мониторинга их статуса с сохранением результатов в базу данных SQLite.

## 🚀 Особенности

- **Асинхронность:** Высокая производительность благодаря использованию библиотек `asyncio` и `httpx`.
- **База данных:** Асинхронное сохранение истории проверок (URL, статус ответа, время отклика) с помощью `aiosqlite`.
- **Консольный интерфейс (CLI):** Простое интерактивное меню для взаимодействия с программой.

---

## 🛠 Технологии

- Python 3.8+
- [httpx](https://www.python-httpx.org/) — асинхронный HTTP-клиент
- [aiosqlite](https://github.com/omnilib/aiosqlite) — асинхронная обертка для SQLite

---

## 📦 Установка и запуск

1. **Клонируйте репозиторий или скачайте проект:**
   ```bash
   git clone <url-репозитория>
   cd Async\ Task\ Manager
   ```

2. **Установите зависимости:**
   ```bash
   pip install httpx aiosqlite
   ```

3. **Запустите приложение:**
   ```bash
   python main.py
   ```

---

## 📂 Структура проекта

- `main.py` — Главный модуль, содержащий точку входа и консольное меню.
- `checker.py` — Класс `PingChecker` для отправки асинхронных запросов и замера времени отклика.
- `database.py` — Класс `DataBase` для инициализации таблицы и сохранения результатов в SQLite (`base.db`).
- `.gitignore` — Список игнорируемых файлов для Git.

---

## 💡 Использование

При запуске программы откроется меню:
```
==============================
Async Task Manager
==============================
1. Проверить сайт
2. Выйти

Ответ: 
```

Введите `1`, затем укажите URL проверяемого ресурса (например, `https://google.com`). Программа выполнит запрос, выведет время отклика и HTTP-статус.
